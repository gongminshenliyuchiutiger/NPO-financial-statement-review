如何取得免費的 Google Gemini API 金鑰？

按照以下簡單步驟，即可取得您自己的免費金鑰：

  1. 前往 Google AI Studio 的 API 金鑰頁面。
  2. 使用您的 Google 帳號登入。
  3. 點擊頁面上的「建立 API 金鑰」(Create API key) 按鈕。
  4. 系統會立即產生一組新的金鑰。點擊金鑰旁邊的複製圖示。
  5. 回到本頁面，將複製的金鑰貼到輸入框中即可！
提醒：請妥善保管您的 API 金鑰，不要與他人分享。AI 服務會消耗一定的額度。

系統使用說明書

系統設定 (API Key)

本系統使用 Google Gemini AI 進行智慧分析。請先取得免費的 API Key 並貼入欄位。

  • 點擊「如何取得？」連結可查看詳細教學。
  • API Key 僅儲存於您的瀏覽器，保障隱私安全。

上傳報表

支援多種檔案格式，請直接拖曳或點擊上傳：

  • Excel 檔 (.xlsx, .xls)：系統自動讀取並進行規則檢核。
  • 圖片/PDF (.jpg, .pdf 等)：透過 AI 辨識內容並轉換為標準格式後進行檢核。

檢核報告與下載

系統將自動分析財務報表並列出檢核結果：

  • 檢核結果：列出通過、警告或錯誤的項目。
  • 修正建議：針對異常項目提供具體的修正方向。
  • 下載報告：點擊底部按鈕即可下載完整的 Excel 檢核報告。
小提示：若遇到問題，請嘗試重新整理頁面或檢查檔案格式是否正確。
